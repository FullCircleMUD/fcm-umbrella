Never contradict Tim flippantly. Before saying he's wrong, or that something won't work, check it fully.

**Why:** sessions have repeatedly told him "this won't work" and been wrong once he dug in, and each one cost him real time and frustration. 2026-10-18: he asked whether to *reintroduce* `@destroy`; I said it was already in, from a grep of the cmdset's class line — `at_cmdset_creation` skips `super()`, so it was out.

**How to apply:** a contradiction needs the full check first: the method body read to the end, the call path followed. If it isn't checked, it isn't a contradiction; ask instead. See [[feedback_cheap_tests_over_theory]].
