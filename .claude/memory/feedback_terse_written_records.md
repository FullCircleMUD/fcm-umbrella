Written records — memory files, working notes, docs — get the same treatment as
replies: terse bullets, not prose.

**Why:** stated 2026-08-18 comparing `.scratch/play_test_notes_2026_08_16.md`
against a memory entry I had written — "in some parts of the world that might be
described as verbal diarrhoea". His notes are one line per item, evidence pasted
raw, no explanation.

**How to apply:** one line per fact. Drop the why-and-how-to-apply scaffolding
unless the why is the fact. Paste the evidence rather than describing it. Cut the
file in half, then look again. Same rule as [[feedback_terse_confirmations]].
