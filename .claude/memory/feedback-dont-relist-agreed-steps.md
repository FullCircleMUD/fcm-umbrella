A report on a finished step says what was done and whether it worked. It does not re-list the agreed remaining steps as caveats ("not done yet: …").

**Why:** Tim works through an agreed list in order; repeating what's already queued reads as nagging and adds noise to the report.

**How to apply:** Mention a later step only when something just learned changes it. Related: [[feedback_terse_confirmations]], [[feedback-dont-second-guess-agreed-scope]].
