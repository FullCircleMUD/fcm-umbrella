On staging (`staging.fcmud.world`) Tim keeps two kinds of account:

- **A superuser account for admin commands** (`wb_build`, `ms_load`, …) — currently **Jimmy**.
- **A plain player account and character for testing as a player** — currently **Tim** / **Paragon**.

The names change whenever Tim feels like it, so treat them as examples and ask if it matters. Both
come back from the archive after a game-database rebuild. The auto-created `fcmadmin` on each
instance is neither.
