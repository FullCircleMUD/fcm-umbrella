`fcm-telemetry-spawn` is **unlicensed**: no LICENSE file, no SPDX headers, `license = "Proprietary"`
plus the `Private :: Do Not Upload` classifier. Distributed by pip from the private GitHub repo, never
PyPI.

**Why:** proprietary to FullCircleMUD, not for outside consumption. Access control is the repo's.

**How to apply:** the `library-standards-linter` reports 2 errors + 1 warn on it (license, missing
LICENSE, missing SPDX). Those are expected — don't "fix" them. The divergence is recorded under
*Working conventions* in the library's `CLAUDE.md`. See [[telemetry-spawn-parked-pending-xrpl]].
