A direct question gets the answer first — no "What we're discussing" header. Tim knows what he asked.

When a header is warranted (a reply genuinely framing a choice), exploratory talk is "discussing", never "deciding".

**Why:** the header restated the question every reply — noise. And "deciding" framed exploration as settled-in-waiting.

**How to apply:** default to no header; use "deciding" only when Tim has said a choice is being made now. Related: [[feedback_no_hardening_language]], [[feedback_terse_confirmations]].
