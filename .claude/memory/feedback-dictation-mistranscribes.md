Tim uses dictation software that often mistranscribes ("dotpile" for stockpile, "lever" for leather, "I want Timber" for Ironwood Timber, "ones" for wands).

**Why:** stated 2026-10-01 — the transcription is not always what he said.

**How to apply:** read each message for its most likely meaning in context and act on it. Confirm in one line only when two readings would build different things; never query an obvious mistranscription. Related: [[feedback_answer_the_concept_not_the_literal]].
