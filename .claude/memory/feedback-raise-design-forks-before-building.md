A design fork spotted mid-task (e.g. freeze superusers' survival meters vs skip the effects) goes to Tim before the code, never as a closing caveat once it's built.

**Why:** asking after building frames a done thing as open; Tim called it out (2026-10-09).
**How to apply:** if the fork could change what gets built, stop and ask first; if it couldn't, leave it out. Related: [[feedback-understand-before-options]], [[feedback-ask-before-a-structural-change]].
